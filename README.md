# AWS-Cloud
Multi-Factor Authentication (IAM) – Configured secure access control using IAM roles and MFA for enhanced account security.
CloudWatch Monitoring – Implemented real-time monitoring and performance metrics for cloud resources.
EC2 Volume Management – Attached and managed persistent volumes on EC2 instances running Linux.
Virtual Private Cloud (VPC) – Designed a secure, isolated VPC network with subnets and routing configurations.
AWS Lambda Automation – Built serverless functions to automate tasks and optimize resource handling.
Elastic File System (EFS) – Configured scalable, shared storage solutions for multi-instance access.
